## 三个开启档

| 选项 | 效果 |
| --- | --- |
| −1 燃料（默认） | 燃料锅、附近火炉供火、炊具净化和便携设备追加红宝石 |
| −2 食材度 | 包含 −1，并把多数食材度减去 0.25 |
| −3 五格锅 | 包含−2，并加入五格锅、鲜度与配方规则；支持永不妥协正式／测试版 |

## 锅的燃料

| 项目 | 数值或条件 |
| --- | --- |
| 适用设备 | 普通烹饪锅、便携烹饪锅 |
| 燃料上限 | 270；新锅初始 2.7（1%） |
| 普通角色开锅 | 满足原有配方条件，且燃料至少为配方 cooktime×20；满燃料时直接通过燃料检查 |
| 沃利开锅 | 通过烹饪动作使用主厨标签时，跳过燃料数量检查 |
| 开始、结束消耗 | 开锅时开始燃烧，收取料理时停止 |
| 熟食留锅 | 做熟后没有收取，燃料仍会继续消耗 |

## 普通锅加速

普通锅开锅时，耗时乘以 1−当前燃料比例÷5。满燃料为 80% 耗时，半满为 90%。便携锅不再叠加这项燃料加速，仍使用自身的 80% 配方耗时。燃料只在开锅前检查；烹饪开始后燃料耗尽，不会取消已安排的完成任务。

例如小糖豆配方 cooktime=1，普通角色需至少 20 燃料；满燃料普通锅约 16 秒完成，未加速的配方时间约 20 秒。

## 龙鳞火炉供火

锅在生成和开锅时，会查找 18 距离内符合结构、热源与防野火标签的龙鳞火炉。找到后把燃料填满并停止消耗。龙鳞火炉生成时，也会给 18 距离内的燃料锅补满。

火炉供火不消耗火炉的任何东西，也不需要开“龙鳞火炉批量烹饪”。所以把锅围着龙鳞火炉摆，就再也不用加燃料了。

## 食材度扣减（−2／−3）

| 原食材度 | 扣减后 |
| --- | --- |
| 1 | 0.75 |
| 0.5 | 0.25 |
| 0.25 | 0 |
| 怪物度、不可食用度 | 不扣减 |
| precook、dried 标记 | 不改 |

## 食材度与材料数量

肉度、水果度、蔬菜度、鱼度、甜味剂、冰度等数值各自减 0.25，最低为 0。原有“至少两个胡萝卜”这种按名称计数的条件仍是两个；“水果度至少 1”则要按扣减后的总和计算。

## 五格锅规则（−3）

| 项目 | 当前规则 |
| --- | --- |
| 普通锅、便携锅 | 改为五格，需放满五格再开锅 |
| 蒸树枝 | 优先级 11；不可食用度、装饰度、冰度任一项 >2，或三项之和 >3 即符合配方 |
| 芦笋冷汤 | 至少两个生熟芦笋，冰度至少 1.5 |
| 炖兔子（未加载永不妥协） | 肉度大于 0 且小于 1，冰度至少 1.5，没有不可食用度 |
| 炖兔子（永不妥协） | 需兔子，冰度 >1.5，没有不可食用度与 foliage 标签 |

## 蒸树枝的优先级

填充物超过上面的量时，蒸树枝会成为候选之一，但优先级比 11 高的料理仍然会赢，不是一律做成蒸树枝。

## 50%～70% 鲜度

五格锅规则开启时，食物仍属新鲜但鲜度低于 70% 的阶段，普通角色的正饥饿收益乘 0.75；有专属陈旧饥饿倍率的角色使用其自身倍率。不额外削减生命或理智，忽略腐坏的角色和负饥饿食物也不受这层乘数影响。

这一档还会取消简单模式给不新鲜食物的饥饿宽免。这类食物名字前会显示“放久的”。

| 对象 | 规则 |

## 永不妥协与动态料理

五格锅兼容永不妥协正式版和测试版。测试版另开启其动态料理属性时，五份食材均参与配方与动态三维计算，保存、收取及料理自身的产量规则保留。五格锅与动态料理同时开启时，即使关闭可选“永不妥协补丁”，防止第五份食材出错的必要适配仍会启用。

## 红晶锅与月炆宝炊

能力勋章红晶锅使用五个食材格，保留自身配方和入锅限制，并接入燃料与附近龙鳞火炉供火。棱镜月炆宝炊的每行变为五份食材加一个产物格；四行版同样按行计算，其他行与已做好的料理不混入本行配方。

调味仍使用料理与香料的原有组合，不要求凑满五份。升级、收起／展开和扩容保留原输入、产物与燃料；燃料不足时补充后继续。

## 智能锅与火炉例外

智能锅（独立版和群鸟绘卷内置版）会按当前锅和五格食材显示预告，换食材、重开、切换月炆行都会刷新。预告只是候选，实际以配方为准。

龙鳞火炉始终是四份食材加红宝石专用槽。五格档位下，火炉读取未扣减0.25的食材度，不套用五格锅的填充物限制与冷汤／炖兔子额外冰度规则；做出的食物仍受50%～70%鲜度饥饿折扣影响。

兼容的智能锅支持右键食材图标，从附近允许取物的容器收集指定食材或食材度。按普通肉度收集会排除带怪物度的食材。月炆宝炊按可见食材格逐行放料，成品格留空。
