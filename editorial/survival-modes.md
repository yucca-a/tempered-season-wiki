荒野求生录是一整套可选的硬核生存规则：做东西更慢更贵、收获减半、下雨点不着火……默认全部关闭，想玩哪条开哪条。

## 怎么开

先开“荒野求生录总开关”（默认关闭），它独立于简单模式和困难模式。然后按需开启下面的“基础生存规则”和各个子项，它们之间互不依赖，可以只挑几条开。

总开关没开时，下面的子项就算显示“启用”也不会生效。

## 基础生存规则

这一项是整套玩法的核心，开启后同时带来下面这些变化：

| 变化 | 具体规则 |
| --- | --- |
| 制作变慢 | 做东西要读条，时间按配方算（见下一节），头顶会显示进度圈 |
| 新装备耐久随机 | 新做的工具、武器、护甲、燃料类装备，初始耐久只有 22%～45% 左右；同一样东西做得越多，初始耐久越高 |
| 收获减半 | 玩家砍树、挖矿、敲石头时，掉落的每种东西减半（向上取整，至少 1 个） |
| 不会永久学会配方 | 在科技台旁做东西不会永久解锁配方，离开科技台就做不了；蓝图和图鉴照常能学 |
| 猪王不给金子 | 只换金子的东西猪王直接拒收；能换图纸的小玩具照常换图纸，只是不再附带金子 |
| 人人都能读书 | 所有角色都能做书、读书（理智消耗正常） |
| 不怕黑 | 黑暗中的查理不会攻击你 |
| 磨刀 | 可以拿燧石、纯粹辉煌或绝望石给武器“磨锋刀刃”（见下文） |

## 制作要多久

制作时间 =（3.5 + 1.35 × 材料种类 + 0.2 × 材料总数 + 0.5 × 科技等级）× 0.5 秒

再按下面两项缩短，两项加起来最多缩短一半：

- 熟练度：同一样东西每做一次，以后做它快 1.5%，最多快 50%
- 戴着建造护符：快约 33%

最终时间最少 1 秒，最多 25.5 秒。比如用 1 种材料、共 2 个的零科技配方，大约 2.6 秒。

## 随机耐久怎么算

新做出来的东西，初始耐久在 22%～45% 之间随机，再加上熟练度：同一样东西每做过一次，以后做出来的初始耐久 +3%，最多到 100%。火把不受影响。

## 磨锋刀刃

拿着燧石、纯粹辉煌或绝望石，对武器使用“磨锋刀刃”（读条动作），消耗 1 个材料：

| 材料 | 效果（持续 120 秒） |
| --- | --- |
| 燧石 | 位面伤害 +15；如果是工具，磨完 6 秒内使用不掉耐久 |
| 纯粹辉煌 | 位面伤害 +15，对暗影阵营目标伤害 ×3 |
| 绝望石 | 位面伤害 +15，对月亮阵营目标伤害 ×3 |

同一种材料重复磨会刷新时间，不会叠加。

## 子项

| 子项 | 默认 | 开启后的规则 |
| --- | --- | --- |
| 种地种树需要书 | 关 | 播种要带园艺学类的书，种树要带应用造林学；每种一次扣书 1 点耐久 |
| 做饭需要书 | 关 | 开锅要带烹饪指南（随身锅也算）。烹饪指南一共 5 次耐久，每开一锅扣 1 次，用完消失 |
| 材料制造翻倍 | 关 | 所有配方的材料数量翻倍；生命、理智等代价不变 |
| 低san采集失败 | 关 | 理智越低越容易采集失败：理智满时 0%，理智为 0 时 50%。失败时作物照样被摘掉，但什么也拿不到 |
| 捡东西变慢 | 关 | 捡东西、采摘、收获都变成读条慢动作 |
| 料理禁止堆叠 | 关 | 锅里做出的料理每格只能放一份 |
| 护甲失效 | 关 | 护甲不挡伤害，也不掉耐久；作为交换，影怪不会主动伤害你 |
| 难以冻结 | 开 | 被冻住后 23 秒内不会再被冻，单次冰冻最多 4 秒 |
| 下雨禁火 | 开 | 下雨时点不着火，火把和打火机立刻熄灭 |
| 火把传热 | 开 | 点着的火把、打火机能给身边的人取暖 |
| 空挥武器 | 关 | 攻击时原地挥武器，不会自动走到最远攻击距离 |

注意“难以冻结”“下雨禁火”“火把传热”这三项本身默认是开的，所以只要打开总开关它们就会生效。

## 子项细节

料理禁止堆叠：本来就能一锅出多份的料理、饮品、各种节日装饰和药水不受影响。旧存档里已经叠在一起的料理会保留数量，但拆开后就合不回去了。

护甲失效：对象是玩家。梦魇尖喙、爬行梦魇和海上恐惧不会主动攻击别的生物，也不能伤害你，除非你在 23 秒内打过它们。

难以冻结：对所有能被冻住的东西都有效，包括 Boss 和你自己。冷却期间的冰冻会直接开始解冻。

下雨禁火：龙鳞火炉、咩咩雕像火堆，以及困难模式天气改动里的防雨火炉不受影响。站在大树之类能挡雨的东西旁边 3 格内时不算淋雨，火把也不会灭。

火把传热：火焰是一个 50 度的小热源，作用范围 4 格，各种皮肤的火把和打火机都算。
