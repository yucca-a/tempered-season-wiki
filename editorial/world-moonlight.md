天体启迪之后，月亮不会一直停在满月；你可以设置哪些月相的晚上有月光照明。

## 启迪后的月相

月相照常变化，晚上有没有月光看当晚的月相在不在你选的范围里。只影响地面，洞穴里没有月光。

## 六档照明范围

| 值 | 有光的月相 |
| --- | --- |
| -1 | 所有月相。 |
| -2 | 除新月外。 |
| -3 | 半月、凸月和满月。 |
| -4（默认） | 凸月和满月。 |
| -5 | 仅满月。 |
| -6 | 所有月相均不提供这一启迪夜光。 |

## 与长夜共同配置

这和“漫漫长夜”是两个独立设置。
