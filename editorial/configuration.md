开房前最值得看一眼的几个设置：默认是什么、要开哪些上级开关，以及老存档升级时会怎么变。

## 先看上级开关

大部分子选项要它所属的模式和分类总开关都开着才生效。荒野求生录有自己的总开关，和简单、困难模式无关。

## 常用设置

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 战斗险境 | 锋芒渐敛 | 需要困难模式 + 角色改动；高倍率逐渐递减 |
| 巨兽装甲 | 遇强则坚 | 需要困难模式 + 怪物改动；按 Boss 最近实际掉的血动态减伤 |
| 穿越机制 | 为爽原版 | 另可选咸鱼版、单人档专用或关闭空间切换 |
| 装备切换优化 | 开启 | 从物品栏换装备时，旧装备放进新装备腾出的格子 |
| 巨兽摧毁 | 80% | 旧存档的 100% 自动按 80% 算；新菜单可以手动选回 100% |
| 荒野求生录 | 关闭 | 独立的硬核生存规则，开总开关后再挑子项 |
| 难度评级 | 开启 | 聊天框或控制台输入 /nd，只有你自己能看到 |
| 怪物角色夜视 | 开启 | 独立开关，不依赖简单／困难模式；夜视不等于防查理 |
| 永不妥协补丁 | 开启 | 要启用永不妥协才有用 |
| 界面拖拽 | 开启 | 右键拖容器窗口、左键拖“查看模组”按钮 |

## 老存档升级时

地面和洞穴请选择同一个穿越档位。从咸鱼版切回原版时，会把咸鱼旧物品还回来。原版里已有的东西仍在原处，空间不够时剩下的先留着，腾出位置后继续还。

战斗险境和巨兽装甲：旧默认的“1档／开启”会分别变成锋芒渐敛和遇强则坚；想用回老规则，在新菜单里选“传统1档”。旧存档里明确选过的 2、3 档不会被改。

## 本机开房的 tick

在游戏里直接开房、并启用了淬炼之季时，这次启动用 60 tick 的通信频率。这不是帧率；独立部署的专用服务器不受影响。

## 困难模式自带的通用限制

只要打开了“困难模式总开关”，下面这些细微规则也会一并生效（没有单独子开关）：

- **流浪商人**：商品刷新间隔延长到 5 倍；齿轮改为 3 猪皮 + 3 蜘蛛丝，活木改为 3 猪皮，猪皮（×3）改为 1 个胡萝卜蛋糕。
- **小丑机**：每局结算或中途放弃后进入 60 秒冷却；最差奖励改为刷 2 只嗡嗡蜜蜂、1 只青年座狼或 2 只悬垂蜘蛛，中途放弃改为刷 2 只火药猴。
- **鎏金骑士**：不掉齿轮，头盔和护甲即使摇中掉落也只有 25% 实际生成；公主召唤冷却延长到 8 倍。
- **棋子雕像**：每个昼夜阶段（白天／黄昏／夜晚）每种棋子最多砸出 1 只。
- **其他限制**：三叉戟水柱不伤飞行生物、暗影分身和陆地上的有血量目标；煤炭陷阱灼烧对 Boss 无效；月亮裂隙开启前，薇诺娜的配方扫描仪不能扫描启迪碎片。

※ 鎏金骑士护甲减伤代码原本想下调头盔和护甲各 5%，但两行都写在了头盔变量上（若原本 ≥90% 会各扣一次），护甲本身未被改动。

## 简单模式自带的隐藏便利

只要打开了“简单模式总开关”，还会附带几项小便利：智囊团旁可制作瓶中信（橙宝石 ×1 + 藏宝图 ×1 + 绳子 ×1）；留声机不可锤毁；猪年／兔年活动料理带料理标签；皮弗娄牛、触手、伏特羊和带电伏特羊死亡时分别多 15%／10%／20%／30% 独立概率再掉牛角、触手皮或羊角；亮茄与果蝇王触电不着火。
