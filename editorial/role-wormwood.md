沃姆伍德收完庄稼会自己补种，吃东西能“长”出装备，还能靠荆棘和几样食物增益上前线。

## 需要开启

简单模式部分：“简单模式总开关”“简单模式角色改动”“沃姆伍德总开关”，再按需打开各项子选项。

困难模式部分：“困难模式总开关”“困难模式角色改动”，以及沃姆伍德的困难开关。

## 种田

| 能力 | 效果 |
| --- | --- |
| 食物回血 | 吃东西回血按 75% 算，饥饿和理智正常 |
| 收获再生 | 沃姆伍德收成熟的作物后，同一格耕地上自动长出一株同种新苗，土壤数据也继承下来 |
| 困难模式再生 | 必须戴着高级耕作先驱帽，每次扣 1.5 饥饿 |
| 安抚加速 | 每个生长阶段第一次安抚成功，剩余时间减少 9% × (开花等级 + 1) |
| 光合作用 | 白天每 5 秒积累 (开花等级 + 1) ÷ (最高开花等级 + 1) 点理智，攒够 1 点就发放 |
| 灵魂滋养耕地 | 沃姆伍德的灵魂在耕地上消散时，清掉那块地的衰败标记，同一格的作物不再消耗水分和养分 |

跟作物说话说到一半被别人抢先照料了，这一阶段的加速照样算。作物烂掉重新长出来后，可以再加速一次。

## 躲藏与休憩

右键自己，戴上临时灌木丛帽躲起来；躲着时再右键可以休息，再右键醒来。主动睡下 2 秒后就能醒。冷却：普通 1 秒，困难 60 秒，从帽子消失或休息结束时开始算。

## 吃出装备：档位 1

吃特定食物时有概率直接长出一件装备，穿到对应的空装备栏上；那一栏已经有东西就不换。临时装备一旦卸下或丢掉就消失。

没长出来的话，下次再吃同一种食物，概率会加上初始概率的一半，长出来后重置。吃非肉类食物时，如果有对应作物的种子，还另有 25% 概率给你一颗种子。

| 食物 | 可能长出 | 初始概率 |
| --- | --- | --- |
| 发光浆果；肉干；象鼻／烤象鼻；冬象鼻 | 鼹鼠帽；火腿棒；透气背心；松软背心 | 各 100% |
| 浆果／多汁浆果；鳄梨酱；蜂王浆 | 灌木丛帽；雨帽；蜂王冠 | 各 50% |
| 小发光浆果；裸露鼻孔；成熟石果 | 鼹鼠帽；牛奶帽；启迪之冠或大理石甲 | 10%；5%；15% |
| 仙人掌肉／熟仙人掌肉；恐怖国王饼；骨头汤；火龙果派；糖豆 | 荆棘外壳；多用斧镐；铥矿皇冠；鳞甲；蜂王冠 | 各 25% |
| 仙人掌花；种子；鱼／蛙腿；鸟腿；生肉 | 花衬衫；耕作先驱帽或高级耕作先驱帽；聪明的伪装；羽毛帽；橄榄球头盔 | 各 25% |
| 带电的羊奶／乳白物；苔藓；犁地草；必忘我；火荨麻 | 牛奶帽；骨头头盔或骨头盔甲；大理石甲；蜂王冠或花环；鳞甲 | 各 25% |
| 花瓣；海带；红蘑菇；绿蘑菇；蓝蘑菇；月亮蘑菇 | 花环；海花环；对应蘑菇帽或孢子；启迪之冠 | 各 25% |
| 西瓜；荧光果；胡萝卜；蝴蝶翅膀；蜂蜜 | 西瓜帽；矿工帽；胡萝卜外套；手杖；养蜂帽 | 各 25% |

## 吃出装备：档位 2

这一档每次吃对应食物都必定长出装备，而且是放进物品栏、可以收着用的，基础保质期 6 天。工具和武器每用一次扣 0.7% 新鲜度，护甲按挡下的伤害扣新鲜度。

困难模式下每长出一件占 0.6 天的额度，额度超过“今天 + 1 天”后暂停，等日子过去再恢复。

| 食物 | 长出 |
| --- | --- |
| 熟肉、烤种子、荧光果、小发光浆果 | 橄榄球头盔、高级耕作先驱帽、矿工帽、鼹鼠帽 |
| 熟红蘑菇、熟绿蘑菇、熟蓝蘑菇、熟月亮蘑菇 | 对应的蘑菇帽 |
| 月蛾翅膀、月树花、熟蝙蝠翅膀 | 启迪之冠、月光玻璃斧、蝙蝠棒 |
| 熟怪物肉、带电的羊奶、蝴蝶翅膀 | 触手尖刺、晨星、手杖 |
| 烤土豆、熟火龙果、苔藓、熟仙人掌肉 | 大理石甲、鳞甲、骨头盔甲、荆棘外壳 |
| 熟小鱼块、熟蛙腿 | 雨衣 |

## 食物增益

吃下面这些东西有 20% 概率获得增益。成功时扣 20 饥饿；如果身上已经有同样的增益，只扣 5 饥饿并刷新时间。

| 食物 | 增益 |
| --- | --- |
| 辣椒或烤辣椒 | 攻击 ×1.2，240 秒 |
| 大蒜或烤大蒜 | 抵挡 1/3 伤害，240 秒 |
| 蜂蜜 | 砍树、挖矿、锤东西效率 ×2，240 秒 |
| 没开的石果 | 抗睡眠 |

## 荆棘与火焰

| 选项 | 效果 |
| --- | --- |
| 刺针旋花 | 触发荆棘时有 25% 概率在附近长出一株刺针旋花 |
| 荆棘伤害 | 荆棘外壳反伤 34，荆棘陷阱 60；不会扎到玩家、随从、牛和鹿 |
| 困难模式荆棘外壳 | 护甲耐久至少再掉 5% 才会再次反伤 |
| 吃东西灭火 | 进食 2 秒后身上的火自动熄灭；着火时间和普通玩家一样，受到的火焰伤害倍率高于 1.25 时降低 0.25 |
