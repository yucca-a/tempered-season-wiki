薇洛换下火炬后，手里的武器还能带着火打人；余烬、火焰狂热和伯尼也都有加强。

## 需要开启

简单模式部分：“简单模式总开关”“简单模式角色改动”“薇洛总开关”，再按需打开各项子选项。

困难模式部分：“困难模式总开关”“困难模式角色改动”，以及薇洛的困难开关。下面表格里的“困难”列，就是开了薇洛困难改动之后的数值。

## 火焰增伤

开启“攻击干燥／燃烧目标”后，薇洛打干燥或着火的目标会有额外倍率。目标湿了、冻住了，或者薇洛在骑牛，倍率都会变。

没有火焰狂热时：

| 目标状态 | 普通 | 困难 |
| --- | --- | --- |
| 潮湿或冻结 | ×1 | ×1 |
| 干燥，没着火也没被烧过 | ×1.5 | ×1 |
| 着火或被烧焦，没骑牛 | ×2.5 | ×1.25 |
| 着火或被烧焦，骑牛中 | ×1.2 | ×1.1 |

火焰狂热期间：

| 目标状态 | 普通 | 困难 |
| --- | --- | --- |
| 没骑牛，目标干燥且正在燃烧 | ×2 | ×1.2 |
| 没骑牛，目标干燥、被烧焦过但现在没着火 | ×2.5 | ×1.5 |
| 没骑牛，其他干燥目标 | ×1.5 | ×1.25 |
| 骑牛中或目标潮湿／冻结，目标正在燃烧 | ×1 | ×0.8 |
| 骑牛中或目标潮湿／冻结，目标没着火 | ×1.25 | ×1 |

## 吸火控火

右键自己放吸火控火，默认冷却 3 秒。开了这项，薇洛的理智上限也会变成 200。

学会余烬技能后，附近有余烬时会优先吸余烬，同时把周围着火和冒烟的东西都灭掉。余烬可以超过普通堆叠上限，死亡、落水都不会丢。

这是直接施法，不会给你一本实体书，理智消耗按 33 算。开了“右键自身需要按住 Ctrl”的话，要按住 Ctrl 才能放。

## 火焰武器

先装上火炬或打火机，再换成别的武器，火焰效果会留在新武器上。前提是那把火炬／打火机还在薇洛身上而且有燃料；把它拿走、烧没了，或者空手，效果就结束。

带火的武器打干燥、没冻住、能烧的目标时，有机会把它点着；学会可控燃烧后就是必定点着。

薇洛用发射普通火焰弹的武器时，子弹换成本模组的火焰弹，基础伤害 34，卸下后恢复。

## 薇洛优化

影火会优先追 Boss 本体。骑牛拿着打火机时，也能灭身边的火、吸余烬。可控燃烧不再烧伤玩家。

## 困难模式

| 机制 | 变化 |
| --- | --- |
| 潮湿的伯尼 | 挨打或格挡时额外掉 34 生命 |
| 巨型伯尼 | 主人理智上限 −15%；巨型伯尼着火时再 −15%，状态结束后恢复 |
| 用余烬施法 | 每消耗 1 个余烬，理智上限 −2.5%；这份惩罚保留 60 秒，再次施法会重新计时 |
| 月火连击 | 连续打同一个目标，每层伤害和位面伤害 −1%，最低保留 60%，10 秒后清除 |
| 蜜蜂掉余烬 | 原本会掉的余烬只有 33% 概率保留 |
