“额外改动”可以单独调高 Boss 和普通怪的血量、移速、伤害和攻速。Boss 血量调高时，掉落也会跟着变多。

## 需要开启

困难模式和“额外改动”，不需要开“怪物改动”。每一项默认关闭，关闭就是不额外加倍率，原版属性和 Boss 专属强化照常保留。

Boss 按“巨兽”标签判断，暗影棋子和帝王蟹也算。普通怪的设置默认只影响有威胁的生物，可以用“非 BOSS 范围”扩大到所有非玩家生物。

## 各项效果

| 设置 | 效果 |
| --- | --- |
| BOSS 血量 | 最大生命乘倍率；和专属强化加的血量继续相乘（比如巨鹿加强后 8000，再选 3 倍就是 24000） |
| BOSS 移速 | 移速乘倍率；有些专属强化会和它取较高者 |
| BOSS 伤害 | 战斗伤害乘倍率；有些直接扣血的技能不经过这里 |
| BOSS 攻频 | 攻击间隔除以倍率；技能自己的冷却不受影响 |
| BOSS 攻击距离 | 普通攻击和用同一范围设置的攻击变远；自定义技能看各自实现 |

巨鹿和龙蝇的攻速有专门协调：倍率低于 1.33 时保留它们加强后约 3 秒的攻击间隔，更高才按倍率算。

## 血量越高，掉得越多

Boss 血量倍率大于 1 时，通用掉落倍率 = (1 + 血量倍率) ÷ 2：

| Boss 血量 | 掉落倍率 |
| --- | --- |
| 关闭或 1 倍 | 1 倍 |
| 2 倍 | 1.5 倍 |
| 3 倍 | 2 倍 |
| 4 倍 | 2.5 倍 |
| 10 倍 | 5.5 倍 |

整数部分必定多给，小数部分每件按概率给。比如原本掉 1 个眼球，2 倍血时必得 1 个、50% 再多 1 个。本来就是概率掉的东西，要先掉出来才会翻倍。

远古系列的化石碎片和暗影心房不翻倍。克劳斯赃物袋、远古守护者宝箱和大霜鲨交易各有自己的处理，见对应 Boss 页。大霜鲨是多给交易次数，每条鱼换几双腿靴还是看鱼的重量。

## 永不妥协的暗影薇希

开着永不妥协时，“多倍血维希兼容”决定暗影薇希怎么套用 Boss 血量倍率：默认“限伤兼容”是血量和每轮撤退门槛（原本 500）一起乘倍率；“倍率兼容”是血量和门槛不变，改为把它的攻击伤害乘倍率。两档都会多给掉落。
