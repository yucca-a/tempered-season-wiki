吃东西的收益打了折：回得少、扣得多。生命、饥饿、理智三项按各自的原始数值查表算倍率。

## 计算方法

三项分开算：每项用它自己的原始数值查下表，再乘对应倍率，不取整。默认是 −1 档。

## 食用数值倍率

| 单项原始数值 x | −1（默认） | −2 | −3 |
| --- | --- | --- | --- |
| x ≤ 0 | ×1.1 | ×1.2 | ×1.333 |
| 0 < x < 10 | ×0.7 | ×0.5 | ×0.3334 |
| 10 ≤ x < 20 | ×0.75 | ×0.575 | ×0.4 |
| 20 ≤ x < 30 | ×0.8 | ×0.65 | ×0.5 |
| 30 ≤ x < 40 | ×0.85 | ×0.725 | ×0.6 |
| x ≥ 40 | ×0.9 | ×0.8 | ×0.6667 |

## 默认选项示例

| 原始数值 | 结算数值 |
| --- | --- |
| 生命 +5 | +3.5 |
| 生命 +20 | +16 |
| 饥饿 +62.5 | +56.25 |
| 理智 +33 | +28.05 |
| 生命 −20 | −22 |

## 不受这张表影响的食物

红、绿、蓝蘑菇和它们的烤熟版本不受影响。其他能吃的东西都会打折，包括本模组的料理和干菜。

小糖豆的持续回复、干菜恢复生命上限这类额外效果不打折，只有吃下那一刻的三项数值打折。

## 同时开启简单模式

| 角色 | 陈旧食物饥饿倍率 | 变质食物饥饿倍率 |
| --- | --- | --- |
| 一般角色 | 0.8335 | 0.75 |
| 薇克巴顿 | 0.6665 | 0.5835 |

## 鲜度与五格锅

上表是食物改动和简单模式同时开着时，不新鲜食物的饥饿收益会好一点。如果“烹饪改动”选了 −3（五格锅），会改回一般角色 0.667／0.5、薇克巴顿 0.333／0.167，并且鲜度在 50%～70% 之间的食物饥饿收益也打折。和永不妥协测试版一起开也一样。

## 相关配置

需要困难模式、困难模式食物改动总开关和“食物改动”。
