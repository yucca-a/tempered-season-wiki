生成新世界时把大陆拆成岛屿、重新安排洞穴连接。只对新世界有效。

## 岛屿级别

| 设置 | 生成分支 |
| --- | --- |
| 关闭（默认） | 不加载复杂地形生成。 |
| true | 随机选择0～4级。 |
| -1～-5 | 分别选择0～4级。 |
| -6 | 按4级岛屿继续拆分部分地表地形任务，形成碎群岛。 |

## 各档共同改动

开启后（包括 0 级）都有：80% 概率没有道路，分支和环形设置重新调整，地面允许生成岛屿，浅海和中海比例重新随机。

## 地表与洞穴

正级别从候选主地形、可选地形及月岛区域中选择孤立区域；级别越高，候选拆分规模越大，但每张地图仍有随机性。碎群岛进一步按房间拆分部分地表任务，可能显著扩大地图。

洞穴会调整蘑菇森林、沼泽、月亮洞穴和远古入口的连接顺序。−6 档的“碎群岛”只拆地面，洞穴不会拆成岛。

## 存档使用

已有的世界改这项不会重排地图。需要困难模式和科技改动总开关。
