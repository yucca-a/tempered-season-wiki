采浆果可能惊出火鸡，挖骨架可能冒出幽灵，捡海带根可能被触手偷袭：采集资源时有概率引来敌人。

## 需要开启

默认开启，需要困难模式和食物改动，与角色改动开关无关。采摘在摘下时判定，砍、挖、敲在完成时判定（不是每挥一下都判定），海滩上的海带根在捡起时判定。

## 概率

| 资源与操作 | 会冒出来的 | 概率 |
| --- | --- | --- |
| 浆果丛（普通、三瓣、多汁）：采摘 / 挖起 | 火鸡 | 1% / 5% |
| 香蕉丛、猴尾草：采摘 / 挖起 | 粉末猴 | 1% / 10% |
| 海里的海带：采 | 触手 | 1% |
| 海滩上的海带根：捡 | 触手 | 35% |
| 普通骨架：敲碎 | 幽灵 | 45% |
| 玩家骨架、海里的遗骸：敲碎 | 幽灵 | 25% |
| 小浮木桩：砍完 | 蛞蝓龟 | 15% |
| 成熟常青树：砍完 | 蝙蝠 | 10%（非白天或在洞穴里；海狸形态不触发） |
| 成熟桦栗树：砍完 | 桦栗果精 | 10%（海狸形态不触发） |
| 芦苇：采 | 触手 / 鱼人 | 10% / 1%（沃特不会引出鱼人） |
| 月亮玻璃矿：挖完 | 月亮裂隙 / 虚影 | 5% / 45% |

石果丛采摘和挖起时，有 5% 冒出虚影；牧者在采摘时 0.1%、挖起时 1%；另外附近已有的沙拉蝾螈会去攻击处于启蒙状态的采集者（不会凭空生成蝾螈）。

有多个候选的资源（石果、芦苇、月亮玻璃）是逐个判定、出一个就停，所以不能把几个概率直接相加。

## 冒出来以后

冒出来的敌人会盯上采集的人；触手直接在资源处钻出来攻击。火鸡生命至少 200，被打会还手。

这一项还把兔子和鼹鼠的生命改成和蜜蜂一样；没有窝、又远离玩家的兔子 10 秒后会被清理掉。
