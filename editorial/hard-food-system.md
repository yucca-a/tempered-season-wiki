困难模式里和吃、种、养有关的改动都在“食物改动总开关”下面，再按分项单独开关。

## 开启顺序

先开“困难模式总开关”，再开“困难模式食物改动总开关”（默认开），最后挑分项。

## 分项与默认值

| 配置 | 默认值 | 主要改动 |
| --- | --- | --- |
| 食物改动 | −1 | 三项食用数值按区间调整 |
| 烹饪改动 | −1 | 烹饪锅需要燃料，部分炊具有概率净化怪物肉 |
| 鸟类改动 | 开启 | 鸟类行为与相关产出 |
| 鱼类改动 | 开启 | 海鱼钓取与死亡相关行为 |
| 动物箱庭 | 开启 | 容器内动物找食物、移动及鱼类捕食 |
| 动物改动 | 8 | 动物生成、成长与部分巢穴恢复倍率 |
| 牦牛改动 | 开启 | 皮弗娄牛相关机制 |
| 考拉象改动 | 开启 | 考拉象相关机制 |
| 植物改动 | 8 | 普通植物生长、再生与周边规则 |
| 互动改动 | 开启 | 采集等互动规则 |
| 种子改动 | 0.8 | 随机种子杂草概率及干种子 |
| 耕地改动 | 开启 | 耕地开裂等规则 |
| 农肥改动 | 开启 | 季节与养分要求 |
| 作物改动 | 2 | 农作物阶段生长时间倍率 |

## 与简单模式的关系

简单模式、困难模式可以同时开启，默认也是同时开启。晾晒蔬菜、治疗怪物肉、用火焰烹饪和批量调味由简单模式分支负责，不受这个困难食物总开关直接管理。

小糖豆、猪鼻胡萝卜蛋糕和四季鱼汤的配方随模组注册；关闭困难食物分支仍可制作。天体洋葱的配方与被动来自怪物分支的天体英雄加强。

## 查数值时看哪些设置

吃一道菜到底回多少：先看食物改动，再看新鲜度、调味和角色忌口。种田看作物倍率；野外植物和动物看植物、动物倍率。锅开不了：先检查燃料、格子放没放满、食材度够不够。
