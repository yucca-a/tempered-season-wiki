海鱼不再任你拿捏：会从手上蹦掉、自己跳回海里，季节鱼还会放技能反击。不过杀鱼时有机会开出宝石、诅咒饰品和瓶中信。

## 档位

需要困难模式、食物改动和“海鱼改动”。默认档包含下面所有内容；另一个“启用（−1）”档去掉了“钓鱼更难”那部分，其他照旧。

## 拿在手上会挣扎

鱼放到鼠标手上时可能蹦走：

| 鱼 | 效果 |
| --- | --- |
| 普通鱼，或者冷却中的季节鱼 | 10% 概率蹦掉 |
| 落叶比目鱼 | 放出孢子云，一定会蹦掉 |
| 花朵金枪鱼 | 放出孢子云，25% 蹦掉 |
| 炽热太阳鱼 | 放出一圈火，4 秒后消失；25% 蹦掉 |
| 冰鲷鱼 | 放出一圈冰，3 秒后冻人、6 秒后消失；25% 蹦掉 |

季节鱼放技能后要 240 秒冷却，每放一次自己少 120 秒保鲜。握得特别牢的角色不会被蹦掉，但挡不住季节鱼放技能。沃特拿鱼完全不受影响。

掉在地上的海鱼会找 15 格内的海，约 2 秒后开始往海里跳；放进容器就不动了。

## 钓鱼更难（默认档）

- 鱼钩离你太近（不到一艘标准船的半径）时，鱼不会上钩
- 鱼第一次可以收竿时，会额外挣扎 2 秒（这 2 秒里收不上来），体力重置为 30%～100%，而且那群鱼剩下的停留时间减半
- 脱钩的鱼会准备游走
- 四种季节鱼会躲开捕鱼网，冷却好了就反击，然后准备离开
- 没人在附近时，捕鱼器的捕获概率只有四分之一，鱼满了逃跑的比例 ×1.5

季节鱼的出现权重：落叶比目鱼（秋季涌浪海域）、冰鲷鱼（冬季涌浪海域）、花朵金枪鱼（春季近海）、太阳鱼（夏季涌浪海域）权重都是 0.25；秋天的落叶比目鱼和春天的花朵金枪鱼在水中木海域权重是 1。


## 杀鱼开宝石

把鱼处理成鱼肉、植物肉或玉米时，按鱼的种类分别判定掉宝石（每种宝石各自判定）：

| 鱼 | 概率 |
| --- | --- |
| 泥鱼、斑鱼、黑鲶鱼 | 紫宝石 3% |
| 浮夸狮子鱼 | 紫宝石 3%，黄宝石 0.1% |
| 玉米鳕鱼 | 黄、绿宝石各 0.1% |
| 花锦鲤、金锦鲤 | 红、蓝各 2%；紫 1%；橙 0.3%；黄、绿各 0.1%；彩虹 0.05% |
| 冰鲷鱼 | 蓝宝石 10%，彩虹宝石 0.02% |
| 甜味鱼 | 红宝石 5%，黄宝石 0.1% |
| 小孔雀鱼 | 红、蓝各 1%；紫 0.5%；橙 0.1%；黄、绿各 0.05%；彩虹 0.02% |
| 针鼻喷墨鱼 | 紫宝石 2% |
| 小饵鱼、三文鱼苗 | 无 |
| 爆米花鱼 | 黄宝石 0.1% |
| 落叶比目鱼 | 红、蓝各 5%，黄 1% |
| 花朵金枪鱼 | 红、蓝各 5%，绿 1% |
| 炽热太阳鱼 | 红宝石 10% |
| 口水鱼 | 蓝宝石 2% |

## 诅咒饰品与瓶中信

诅咒饰品基础 1%，每处理出一份大鱼肉或植物肉 +2%，每份小鱼肉或玉米 +1%；鱼的重量达到 70% 的大鱼还会更高。

大鱼还会另外判定瓶中信，概率是“不算大鱼加成时饰品概率的 2 倍”。宝石、饰品、瓶中信各自判定，可能一次全中。

## 冰鱼、热鱼的温度

冰鲷鱼和太阳鱼越不新鲜，供暖或降温效果越弱：拿在身上时按新鲜度算（最少 35%），放在地上时按新鲜度的一半算（最少 25%），其余部分按环境温度。

## 其他

独角鲸会直接吃掉海鱼，不再吐出来。饼干切割机跳得更快（随机 1～2 倍）。
