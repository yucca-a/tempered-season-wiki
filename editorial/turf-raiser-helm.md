戴上头盔，放入工具或材料，就能边走边种植、工作和捕捉。

## 获取方式

击败蚁狮可获得刮地皮头盔蓝图。原版也可把沙滩玩具交给蚁狮换取蓝图；学会后制作。

## 制作配方

| 材料 | 未启用蚁狮加强 | 启用蚁狮加强 |
| --- | --- | --- |
| 牛毛 | 5 | 5 |
| 猪皮 | 3 | 3 |
| 沙之石 | 1 | 10 |
| 沙滩玩具 | — | 1 |
| 橙宝石 | — | 2 |

## 使用方法

把物品放入头盔的格子，戴上后在要工作的区域移动。手上拿着可用工具时优先用手持工具，随后才尝试格子里的工具；种植和部署时应先收起手持工具。材料用完后会从物品栏补入同种物品。头盔本身自带护目镜防护，可防沙尘暴（开启月岛护目镜分类时，在月亮风暴或永不妥协暴风雪里不通用）。

## 放入物品

| 物品 | 用途 |
| --- | --- |
| 斧、镐、铲、锤、捕虫网等工具 | 处理附近支持对应动作的目标；锤子需放在头盔格子中 |
| 锄头或黄金锄头 | 耕地；每次放入还会切换 3×3／1×3 种植模式 |
| 种子 | 种入所在农田的空土堆；1×3 模式按玩家所在的列种植 |
| 松果、植物根茎等可种植物 | 在可放置位置种下，消耗相应材料 |
| 地皮 | 沿用头盔铺地皮功能 |
| 肥料、浇水壶 | 为附近适用目标施肥、浇水 |
| 手杖或懒人魔杖 | 重置附近已触发、可复用的陷阱，也可部署拾起的海星陷阱 |
| 可晾晒的食物 | 放入附近有空位且可存入物品的晾肉架 |
| 陷阱／捕鸟陷阱 | 自动捕捉 2.5 范围内的小动物／鸟，每 0.25 秒检查一次 |
| 空瓶子 | 收集 2.5 范围内可装瓶的小恶液，获得恶液瓶 |

## 捕捉消耗

成功捕捉沿用陷阱本来的产物和耐久结算，头盔另消耗 1 次使用次数。青蛙交付蛙腿，鸟和蜘蛛等按原有规则变成可携带的捕获物，不会额外复制一只活体。最后一次陷阱耐久仍会交付产物。物品栏满时停止自动捕捉；玩家随从不会被捕捉。

陷阱已有捕获物时先交付，不会被新的目标覆盖。目标不符合原有捕捉资格或捕捉被拒绝时，不扣头盔与陷阱耐久。

每次成功装恶液消耗 1 个空瓶子和头盔 1 次使用次数；仍执行空瓶原来的使用条件和结果。装瓶失败时不生成产物，也不扣这次材料。

## 修理

头盔原始耐久为 400 次。用沙之石右键修理，或直接把沙之石放进格子：未启用蚁狮加强时每块恢复 20 次，启用蚁狮加强后每块恢复 10 次。

## 相关配置

需要开启“简单模式总开关”和“超级高效刮地皮头盔”。配方加价与修理量减半还需要“困难模式总开关”“怪物改动”和“蚁狮加强”生效。

## 工具本身的能力与代价

头盔使用强化多用斧镐采远古雕像时，保留强化工具避免额外法术和影怪的效果。实际使用暗影斧砍树时，仍承担暗影斧原有的理智代价；用头盔中的镐采矿，不会误扣手持暗影斧的工作理智。

头盔使用亮茄粉碎者耕地时按单个土堆结算，不会再叠加批量耕地造成的额外工具损耗。伍迪普通斧头转成露西的原有行为保留。
