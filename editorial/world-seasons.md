混乱之季会打乱四季顺序，可能连着来两个冬天；温度也会按前后季节一起变化。

## 混乱之季档位

| 值 | 实际规则 |
| --- | --- |
| 关闭 | 不额外启用随机季节。 |
| -1 | 通常混乱，启用原版月亮风暴时停止混乱。 |
| -2 | 仅启用原版月亮风暴时通常混乱。 |
| -3（默认） | 仅在原版月亮风暴存在时进入恶劣混乱。 |
| -4 | 始终混乱，启用原版月亮风暴时转为恶劣混乱。 |
| -5 | 始终恶劣混乱。 |

## 正常混乱与恶劣混乱

正常混乱每次抽取与当前不同的下一季。恶劣混乱允许再次抽到同一季，候选池中秋季 1 份、其余三季各 3 份。

“月亮风暴存在”指原版月亮风暴已经启动或正在活动。随机季节的温度会参考前后两个季节，连着两个冬天或夏天时温度曲线会相应变化。

## 世界温度与兼容

该天气体系的季节曲线使用冬季 −25、夏季 95 的基础极值；实际世界温度还会受昼夜、天气与连续季节过渡影响。检查温度测量仪时，会全服播报当前世界温度、季节温度和时段温度；同时放宽了冬天克劳斯赃物袋的生成上限。

需要困难模式和天气改动。装了岛屿冒险时，热带季节只用在对应的世界（2.8.14.98.2 修复了地表误用热带规则导致的崩溃）。
