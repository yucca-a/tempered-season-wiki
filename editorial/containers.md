容器可整理、收集同类物品，也可用快捷键在库存与容器之间存取物品。

## 容器按钮

地面容器的跨整和收集不会跨越不同船只。携带懒人护符时，收集还会拾取地面上的同类物品。

在聊天栏输入“显示整理”“隐藏整理”或“默认整理”，可以调整整理按钮的显示。

| 按钮 | 用法 |
| --- | --- |
| 整理 | 整理当前容器；双击背包的整理按钮，可连同人物库存一起整理。 |
| 跨整 | 背包与人物库存合并整理；随身容器整理携带的同类容器；地面容器整理附近同名容器。 |
| 收集 | 按当前容器内已有的物品，收集其他容器中的同类物品。随身容器从携带的容器收集，地面容器从附近容器收集。 |
| 锁定 | 记住容器中现有的物品种类，此后只允许这些种类放入。解锁可取消限制，右键锁定按钮可查看允许存放的物品。 |

## 整理时固定格子

把鼠标停在物品栏或背包格子的右上角约 0.8 秒，再点击出现的空心图钉。固定后，实心图钉会一直显示，点一下就能取消。

整理和跨整会跳过固定格，空格也能固定。你可以照常拿取或放置物品，鼠标拿着物品时点图钉也会照常放置。物品栏和背包分别记住你固定的格子。

图钉按存档保存。同一存档重进、回档或往返地面和洞穴时沿用原来的图钉。换到其他存档时使用那个存档的图钉。重新生成世界后，格子要重新固定。

## 快捷存取

“道具快捷收集存放”可以分别关闭收集或存放。启用“快捷收集存放功能险境”且开启角色改动总开关时，成功转移物品会消耗饥饿值。

| 操作（默认键位） | 效果 |
| --- | --- |
| Ctrl + 右键库存物品 | 存放物品。 |
| Ctrl + Alt + 右键库存物品 | 收集同类物品。 |
| 右键制作栏中的材料 | 收集该配方所缺的材料；材料已经足够时，继续收集同类材料。 |

## 懒人护符快捷键

在「快捷键绑定配置」里绑定「快捷收集」或「快捷整理」。只要物品栏或背包有可用的懒人护符，即使没背包或鼠标正拿着别的东西，也能按键。

「快捷收集」和拿着护符按 Ctrl + 左键的效果相同。先把地上同款物品补进你打开的箱子或冰箱，再补物品栏和背包。每个地方只收自己已有的种类。点容器的「收集」按钮时，先补点中的容器，再补其他打开的容器。

「快捷整理」和拿着护符按 Ctrl + 右键一样，分别整理人物物品栏、背包和打开的箱子、冰箱等容器。每处单独归位、叠堆，固定格照旧。

## 配置档位

“道具快捷收集存放”默认启用收集和存放。两项配置均不依赖简单模式或困难模式。跨整和锁定由不同档位提供，不能同时显示。

| 容器整理收集按钮 | 效果 |
| --- | --- |
| 禁用 | 不显示容器整理收集按钮。 |
| 启用 · 无额外按钮（−1） | 显示整理和收集。 |
| 启用 · 跨容器整理（−2） | 额外显示跨整按钮。 |
| 启用 · 锁定道具（−3，默认） | 额外显示锁定按钮。 |
| 启用 · 禁用收集（−4） | 不显示收集按钮。 |
| 启用 · 禁用整理（−5） | 不显示整理按钮。 |
| 启用 · 无提示文字（−6） | 显示锁定按钮，隐藏按钮提示文字。 |

## 穿越与空间切换

“穿越机制”默认是为爽原版，也可选咸鱼版、单人档专用或关闭空间切换。单人档专用会把 A、B 两页随角色保存，点「穿越」翻页。整理、收集和锁定继续按各自的设置生效。

## 咸鱼版切回原版

帽子和钓具旧物品会尝试恢复到原版空间，保留已有库存。容量不足时剩余物品继续保存，腾出位置后恢复；钓具入口会对应当前有效空间。

## 永不妥协容器装备的地图图标

同开永不妥协，并开启困难模式、天气改动和“玩家温度”时，没有自带小地图图标、可装备在身体或背包栏的容器装备，会补上跟随该物品位置的背包图标。这个图标功能跟着“玩家温度”走，和容器整理的开关无关。
