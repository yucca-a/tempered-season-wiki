沃拓克斯的灵魂再也不会溢出，可以拿灵魂当飞镖砸人；三项状态都很健康时，近战伤害能翻一倍。

## 需要开启

简单模式部分：“简单模式总开关”“简单模式角色改动”“沃拓克斯总开关”，再按需打开各项子选项。

困难模式部分：“困难模式总开关”“困难模式角色改动”，以及沃拓克斯的困难开关。

## 食物与灵魂

| 选项 | 效果 |
| --- | --- |
| 普通食物收益 | 吃东西的生命、饥饿、理智都按 75% 算（不是 100%） |
| 灵魂不溢出 | 灵魂几乎没有上限（999999），死亡、落水都不丢 |
| 自动获得灵魂 | 生命、理智、饥饿都在 75% 以上，且身上加灵魂罐里的灵魂不到 10 个时，每 120 秒（困难 240 秒）补 1 个 |
| 首传免费 | 连续灵魂跳跃时，第一跳不扣灵魂；技能给的额外免费跳也照算 |

## 状态好就打得疼

三个条件分别加成，可以叠加，骑牛时不生效：

| 条件 | 普通／困难 |
| --- | --- |
| 理智 ≥ 95% | +35%／+25% |
| 生命 ≥ 85% | +35%／+25% |
| 饥饿 ≥ 90% | +35%／+25% |
| 三个全满足 | ×2.05／×1.75 |

用灵魂当武器时伤害是固定的，不吃这个加成。

## 扔灵魂

灵魂可以拿在手上当武器：攻击距离 8，最远飞 15 距离，会追踪目标，打中或者飞完就消失。伤害取决于目标的最大生命：

| 目标 | 每个灵魂的基础伤害 |
| --- | --- |
| 最大生命低于 23 的小东西 | 15 |
| 最大生命 23～46 | 23 |
| 最大生命 46～98 | 46 |
| 最大生命高于 98 | 98 |
| 任何 Boss | 46 |

※ 最大生命恰好是 23 或 98 的非 Boss 目标，按 46 算。

## 和永不妥协测试版一起玩

开着永不妥协测试版的沃托克斯改动时，双尾心的自动免死有 120 秒冷却，换一颗心也得等冷却结束；手动复活不受影响。

2.8.14.98 修复了召唤墨荒跳过正常进度、提前拿到暗影碎布的漏洞。

## 困难模式

灵魂治疗照常回血，但被治疗的人会额外掉饥饿（相当于分到的基础治疗量的一半），同时恢复 1% 的生命上限惩罚。旺达不算在受治疗的人里。兽化中的伍迪（开了饥饿代替变身值时）还会扣变身值。

蜜蜂原本会掉的灵魂，只有 33% 概率保留。开着自动获得灵魂时，排箫不再让动物忘记仇恨，免费排箫的灵感要等 4 天。
