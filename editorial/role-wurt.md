沃特吃顿饭就能拉起一支鱼人队，顺便续上忠诚；拿鱼跟普通鱼人换东西，还能换出金块。

## 需要开启

简单模式部分：“简单模式总开关”“简单模式角色改动”“沃特总开关”，再按需打开各项子选项。

困难模式部分：“困难模式总开关”“困难模式角色改动”，以及沃特的困难开关。

## 吃饭招鱼人、续忠诚

| 能力 | 规则 |
| --- | --- |
| 招募野生鱼人 | 20 范围内没主人的鱼人；饥饿不超过 101 时招 1 只，高于 101 时最多 1 + ⌊(饥饿 − 100) ÷ 2⌋ 只 |
| 招募代价 | 第一只免费，之后每多招 1 只扣 2 饥饿；仍受随从总数上限限制 |
| 续忠诚 | 只给忠诚低于 30%、又不是永久跟随的鱼人续，每只最多连续续 3 次 |
| 续几次 | 饥饿不超过 151 时续 1 次；高于 151 时最多 1 + ⌊(饥饿 − 150) ÷ 2⌋ 次，第一次之外每次扣 2 饥饿 |
| 续多久 | 普通鱼人和鱼人守卫按原版的喂食时长算，有鱼人王时还有国王加成 |

## 拿鱼换东西

把鱼交给普通鱼人：你得是鱼人（或者戴着鱼人伪装），对方也没在打你。每只鱼人每天只额外给一次奖励，第 1 天没有。

奖励从下面 7 组里随机抽，抽过的暂时不再出，全抽完再重新来：

| 组别 | 数量 |
| --- | --- |
| 海带（两组） | 2～4／2～3 |
| 种子 | 4～6 |
| 触手皮 | 1 |
| 芦苇 | 1～2 |
| 小玩意 | 干瘪触手、臭气制造器、熔化的弹珠、弯曲的叉子或橡胶塞，任选其一 |
| 作物种子 | 1～2 份榴莲、辣椒、茄子、南瓜、洋葱或大蒜种子 |

抽到后四组时，还会附送 3 份种子或海带。

鱼越好，给得越多：

- 大重量的鱼：主奖励和附送各多 1～2 份
- 小型海鱼：额外 1～2 个金块；中型海鱼：额外 2～4 个
- 两种活动鱼：金块换成幸运黄金

开了这项后，还可以给普通鱼人塞武器让它拿着，换武器时旧的会掉出来。

## 杂食、书与鱼人王

开启杂食后，荤菜（非蔬菜、非零食）只给 30% 的生命和饥饿、70% 的理智，负面效果照扣。同时海带盘里的东西永远新鲜，沃特右键自己还能放园艺学简编，冷却 240 秒，理智消耗按 33 算。

“制作鱼类之书”只解锁鱼类之书这一本，不会开放所有魔法书。

“鱼人王不饥饿”让鱼人王不再饿；如果它已经饿了，先补到 50% 再停。

夜视由独立的“怪物角色夜视”控制；同时开着沃特的简单角色强化时，晚上不掉理智。

## 困难模式：鱼人守卫

| 项目 | 数值 |
| --- | --- |
| 开启鱼人堡垒／守卫强化 | 堡垒配方：木板 ×10、触手皮 ×2、长矛 ×2、猪皮 ×2 |
| 没有鱼人王 | 守卫生命 600、伤害 40 |
| 有鱼人王 | 守卫生命 800、伤害 70 |
| 月灵鱼人 | 生命再 +200，荆棘反伤 50 |
| 三叉戟加持 | 三连击每一下都是满伤害 |
| 关闭守卫强化 | 没鱼人王时，守卫按普通鱼人的生命和伤害算 |

## 困难模式：其他

鱼人王宝座要多一把刺耳三叉戟。没有鱼人王时，堡垒也会派守卫出来。暗影改造地形的触发概率降到原来的 1/2.5；王冠加持的闪避只有原来一半的成功率。

普通鱼人和守卫刷出来时，有 10% 概率掉落改成 1 条活鱼加 1 只青蛙。

开了“右键自身需要按住 Ctrl”的话，要按住 Ctrl 再右键自己。
