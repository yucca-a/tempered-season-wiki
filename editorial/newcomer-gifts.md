新角色第一次出生时会收到一个礼物包：两颗小糖豆，按加入的日子还可能附送季节装备。

## 什么时候发

新人礼物默认开启，但实际要困难模式、困难科技改动和“暗影之门”都开着，而且暗影之门不能选“禁用单次初始物品机制”。它虽然放在简单角色设置区，但和简单模式无关。

按“账号 + 角色”记录：一个账号第一次用某个角色出生时发一次，同一角色再进来不会重发；换一个没用过的角色会再发。

## 礼物包里有什么

基础是 2 颗小糖豆。如果世界的“复杂地形”是梦幻机碎群岛，还会附送草筏套装和战桨，方便一开始就出海。

## 按日子附送的装备

| 加入时是第几天（每 70 天一轮） | 附送 |
| --- | --- |
| 1～10 | 无 |
| 11～30 | 牛角帽、暖石、火把 |
| 31～40 | 牛角帽、暖石、雨衣、火把 |
| 41～50 | 雨衣、火把 |
| 51～67 | 花衬衫、暖石 |
| 68～70 | 无 |

只在前 210 天内有效。这是按天数算的，不看当前实际季节；改过季节长度或起始季节的世界，送的装备可能和眼前的天气对不上。
