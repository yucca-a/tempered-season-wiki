暗影世界会给生物配上影分身，一只怪变成两只（或更多）打你。这里讲分身有几个、谁会有、死了多久回来。

## 分身从哪里来

“生物暗影分身数目”默认 1，可选 1～3 个或关闭。暗影生物、不会动的东西和部分特殊对象没有分身；几种宠物有专门的分身玩法。

没开困难模式时，暗影世界只给宠物白名单里的对象生成分身，怪物不会有。

## 生成范围

| 选择 | 效果 |
| --- | --- |
| 大部分（默认） | 满足条件的大部分生物。 |
| 非 Boss / 仅 Boss | 按是否为 Boss 缩小范围。 |
| Boss 残血 | 普通生物照常，Boss 降至 25% 或 2500 生命以下后满足生成条件。 |
| Boss 特殊 | 部分受强化 Boss 使用半血阈值，其他对象按该档分支处理。 |
| Boss 半血 | Boss 到 50% 或 5000 生命以下后满足生成条件。 |
| 仅 Boss 残血 | 仅 Boss，且需满足残血阈值。 |
| 仅宠物 | 保留专门支持的宠物分身。 |

## 总量与复活

全世界普通分身默认最多 12 个，Boss 和白名单宠物不占名额。名额满了生不出分身时，本体会获得一些减伤作为补偿。

分身死后默认 480 秒复活。菜单里显示“1”的那一档是 1 秒就复活，不是关闭复活。部分 Boss 在“分身削弱”下另有固定复活时间。

## 变形与读档

发条生物、高脚鸟、石虾、皮弗娄牛及部分永不妥协蠕虫的分身在读档、收纳放出、自我修复、成长或变种后仍保留影子身份。猪人和猪人守卫的影子会随本体变成疯猪，再随本体复原。

万圣节期间，分身跟随本体已有的木乃伊鱼人、科学怪猪等节日形态，不再独立随机变形并重置分身属性。

分身不能被腐化成会正常掉东西的真身；织影者的分身也不能和本体一起放地下三王的腐化仪式。

棱镜普通与辉煌颤栗树的影子死亡、回收时只结束自己的战斗，不会额外生成一棵真树或重复结算本体产物。本体正常结束战斗和还原树木的规则保留。
