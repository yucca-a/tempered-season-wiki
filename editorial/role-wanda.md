旺达可以不再自然变老，钟表更好用，右键就能倒走或闪现，死了还能自己复活；恐惧-警告表另有开关。

## 需要开启

简单模式部分：“简单模式总开关”“简单模式角色改动”“旺达总开关”，再按需打开各项子选项。

困难模式部分：“困难模式总开关”“困难模式角色改动”，以及旺达的困难开关。

## 年龄与回复

| 能力 | 效果 |
| --- | --- |
| 停止自然衰老（默认开） | 不会随时间变老，受伤照样会老 |
| 旺达加强 | 老年门槛改为剩余生命 34%；自然衰老变慢到每秒 0.02 岁（和上一项同开时，以不衰老为准） |
| 不老表控温 | 用不老表时，体温向 35 度靠拢三分之一的差距，并限制在 11～59 度 |
| 钟表加强 | 不老表的治疗量设为 25；倒走表放完后有 0.3 秒闪避 |
| 花瓣转恶魔花瓣 | 吃 1 片花瓣得 1 片恶魔花瓣，并学会噩梦燃料配方 |

## 钟表制作

| 物品 | 变化 |
| --- | --- |
| 裂开的不老表 | 不老表 ×1、时间碎片 ×1、蓝宝石 ×1；每次用掉 1/3 耐久 |
| 警钟开局可做 | 直接学会警钟，配方多要 1 颗黄宝石 |
| 困难模式溯源表 | 配方多要 1 颗橙宝石 |
| 困难模式第二次机会表 | 配方多要 1 颗绿宝石 |

## 警钟夹击

开了钟表加强后，旺达用警钟打中敌人时，会召唤幻影从两侧夹击，1 秒触发一次；老年时多一个，从三个方向打。

每次夹击造成 7 点普通伤害加 10 点位面伤害，不吃辣椒、电击这类加成，也不会打到玩家、阿比盖尔、伯尼、随从和鹿。旺达加强和旺达困难都开着时，普通警钟的暗影武器基础伤害是 68。

## 右键位移

| 选项 | 效果 |
| --- | --- |
| 原版倒走 | 跟倒走表一样往回走，冷却 1.5 秒 |
| 往正后方倒走 | 朝身后退，冷却同倒走表 |
| 向前闪现 | 朝前闪，冷却按所选秒数；和倒走同时开时以闪现为准 |
| 需要 Ctrl | 由“右键倒走需要 Ctrl”单独控制 |

## 右键自己：回溯

右键自己用一块临时的溯源表：先标记地点，之后再用就传送回去。操作冷却 3 秒，真正传送后要等原版溯源表冷却的 3 倍时间。标记点和剩余冷却会保存。

## 自我复活

变成鬼魂时，如果冷却好了，可以点复活按钮，效果和第二次机会表一样，复活后按第二次机会表的冷却重新计时。配置选 −1 时所有角色都能用，其他档只有旺达能用。

## 给怀表起名

开启“溯源表／裂缝表命名”（默认开）后，拿着羽毛笔右键真实的溯源表或裂缝表，就能给它起名字，最多 32 个字。羽毛笔不消耗；升级、使用、读档后名字都会保留。右键技能用的那块临时表不能起名。

表多了分不清哪块记的是哪儿时，这个很好用。
## 恐惧-警告表

旺达可以用 1 个附身暗影心房升级警钟。这项有自己的开关，就算关了旺达简单总开关也能单独开。
